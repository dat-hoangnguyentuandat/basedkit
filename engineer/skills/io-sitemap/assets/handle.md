# handle.md

## 1. Intake
1. Read the sitemap output.
2. Group pages by template/section.
3. Identify missing business/content/asset inputs.
4. Record assumptions and blockers.

## 2. Content modeling
1. Define reusable page sections.
2. Define shared content types:
   - products/services
   - testimonials
   - FAQs
   - blog/news
   - contact/location data
3. Map structured content to the pages that consume it.

## 3. Page planning from sitemap
1. Convert each sitemap node into:
   - page
   - template
   - component set
   - required CTA/form/media
2. Mark which sections are reusable vs one-off.

## 4. Design application
1. Apply brand logo, colors, typography, imagery rules.
2. Build shared UI primitives:
   - buttons
   - cards
   - forms
   - navigation
   - footer
3. Keep consistency across desktop and mobile.

## 5. Content population
1. Insert approved content into each page section.
2. Attach correct media to each block.
3. Add SEO/meta content per page.
4. If content is missing, use a tracked placeholder policy instead of silent invention.

## 6. Functional implementation
1. Wire every button to its destination or action.
2. Implement all forms with validation and submission handling.
3. Implement search/filter/sort behavior if required.
4. Handle 404, empty states, redirects, and external links safely.

## 7. Responsive implementation
1. Validate layouts on desktop.
2. Adapt for tablet.
3. Adapt for mobile.
4. Re-check nav, sliders, forms, and media blocks on small screens.

## 8. QA
1. Test every internal link.
2. Test every CTA/button.
3. Test every form.
4. Test responsive behavior.
5. Test media rendering.
6. Test SEO/meta presence.
7. Fix dead links, layout breaks, and missing content.

## 9. Launch readiness
1. Run final content review.
2. Run final functional review.
3. Confirm sitemap coverage is complete.
4. Prepare deployment/handoff notes.

## 10. Risks / dependencies
- Missing content or brand assets
- Unclear CTA behavior
- Missing integration/API access
- Hidden/gated pages not covered by sitemap
