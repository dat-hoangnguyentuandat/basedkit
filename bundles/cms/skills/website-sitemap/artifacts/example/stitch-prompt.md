# Design Nha Khoa Kim Ngân

Create responsive Vietnamese desktop and mobile screens for a reassuring local dental clinic. Use a clean, warm, professional visual direction with accessible contrast and authentic clinic imagery placeholders.

## Screens

- Home: hero, service preview, trust content, reviews, appointment CTA.
- Services: scalable service-card listing and intentional empty state.
- Contact: verified contact details and appointment enquiry form.

Use the navigation, content sources, and page order from `sitemap.json`. Do not invent treatments, prices, credentials, medical outcomes, opening hours, ratings, addresses, or phone numbers. Keep all visible content suitable for CMS editing and make repeated components visually consistent.
